# Trueque Ya

App Android para hacer trueques de artículos nuevos o usados.

## Funciones
- **Explorar:** lista de artículos consumidos desde la API de [DummyJSON](https://dummyjson.com), con búsqueda y filtro por estado (Nuevo / Usado).
- **Detalle:** información del artículo y opción de proponer un trueque con uno de mis artículos.
- **Mis cosas:** publicar y eliminar mis artículos.
- **Trueques:** ofertas recibidas (aceptar / rechazar) y enviadas (cancelar).

## Tecnologías
- Kotlin + Jetpack Compose (Material 3)
- ViewModel + StateFlow
- Retrofit + Gson
- Coil
- Navigation Compose
